# CyberBlog (TheEddu)

Um repositório de artigos e estudos sobre Segurança da Informação, programação e temas relacionados (hacking ético, privacidade, produtividade e mais). Este projeto serve como espaço de aprendizagem para compartilhamento de conteúdo técnico e didático.

---

## Funcionalidades principais
- Home responsiva com listagem de artigos.
- Filtro por tags para encontrar artigos por tema.
- Páginas individuais de artigos (em `artigos/`).
- Layout simples e facilmente extensível (HTML, CSS, JS).
